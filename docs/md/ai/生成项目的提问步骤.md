1. ### 第一步：先把大白话转成“万能模板”提问

   当你有了一个模糊想法，别急着让它写代码。先用下面这个“万能改写公式”让它帮你把需求打磨清晰。这个技巧非常关键，原文也重点强调了。

   **你可以这样问 Codex：**

   > 我有一个想法：
   >
   > 【在这里粘贴你的大白话描述，例如：我想做一个能帮我把聊天记录自动整理成待办事项的工具】
   >
   > 请你帮我把它转成一个用于 AI 编程的完整 prompt，要求：
   >
   > 1. 明确功能模块
   > 2. 给出输入输出结构
   > 3. 指定技术栈（如 React + Node.js）
   > 4. 拆分开发步骤
   > 5. 输出格式要清晰

   👉 **做完这一步，AI 会给你一份专业版的 Prompt 草稿，你直接复制粘贴进行第二步。**

   ------

   ### 第二步：套用“结构化 Prompt 模板”（核心步骤）

   拿到 AI 帮你优化的内容后，或者如果你想自己手写，直接套用下面这个模板填空。这是原文中 **二、** 部分的精华。

   **请复制以下框架，填入你的信息后再发给 AI：**

   markdown

   ```
   # 角色
   你是一个 [ 资深全栈工程师 / Python 后端专家 / 前端架构师 ]，擅长 [ 你的技术领域 ]。
   
   # 任务
   实现一个 [ 项目名称，例如：智能聊天记录转待办助手 ]。
   
   # 功能需求（越细越好，可以列点）
   1. 用户上传/输入 [ 数据形式，如：一段文本 ]。
   2. 点击按钮后生成 [ 期望结果，如：按紧急程度排序的待办清单 ]。
   3. 额外功能：[ 例如：支持导出为 Excel ]。
   
   # 技术要求
   - 前端：[ React + Tailwind / Vue / 纯 HTML ]
   - 后端：[ Node.js (Express) / Python (FastAPI) ]
   - 模型调用：[ OpenAI API / 本地模型路径 ]
   - 数据返回：[ 流式返回 Stream / 普通 JSON ]
   
   # 输入输出格式（这决定了 AI 怎么解析数据）
   输入示例：
   {
     "text": "这是一段具体的聊天记录..."
   }
   
   输出示例：
   {
     "todos": [
       {"task": "买咖啡", "priority": "高"}

     "summary": "共提取3条待办"
   }
   
   # 约束条件
   - 代码必须模块化。
   - 每个文件需包含必要注释。
   - 给出完整的项目文件目录结构。
   
   # 额外要求
   先给我一个实现方案和技术架构图描述，确认无误后再写代码。
   ```

   ### 第三步：遵循“三步走”对话策略（防 Bug 关键）

   原文提到一次性让 AI 写全部代码很容易出 Bug 且难以维护。**请严格遵守以下对话顺序，不要跳步：**

   | 轮次        | 你要发给 AI 的指令                                     | 目的                     |
   | :---------- | :----------------------------------------------------- | :----------------------- |
   | **第 1 轮** | “先帮我设计系统架构和 API 接口定义，**不要写代码**。”  | 对齐思路，避免后续返工。 |
   | **第 2 轮** | “架构没问题。请先实现后端核心逻辑（或前端静态页面）。” | 先啃硬骨头，拆解复杂度。 |
   | **第 3 轮** | “基于刚才的后端逻辑，帮我补充前端交互和样式。”         | 组装完整功能。           |
   | **第 4 轮** | “请检查代码中的潜在错误并增加错误处理机制。”           | 优化与收尾。             |

   ### 💡 附赠两个提升效果的“必杀技”

   1. **给例子（Few-Shot）**：
      如果你希望输出的格式非常特殊，直接给 AI 一个“示例输出”。原文提到 **“AI 会 100% 模仿这个格式”**。
      - **对话时说**：“请你参考以下格式输出：`{ "title": "xxx", "list": [] }`”
   2. **角色扮演**：
      开头永远先说一句：**“你是一个资深全栈工程师。”** 这句咒语能让代码质量上一个台阶。
